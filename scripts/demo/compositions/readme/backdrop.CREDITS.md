# README backdrop

`backdrop.jpg` is an original image generated for this composition with an
image-generation model (October 2026): a twilight lake valley, misty hills, and
foreground pines, prompted as a photographic desktop wallpaper with no people,
text, logos, devices, or UI. It is not derived from Apple or any other
operating-system wallpaper.

Stored as the generated 1672×941 image, re-encoded once as a quality-90 JPEG.
The composition scales it to cover the frame and softens it slightly.
